Context Feature Fusion experiments
The current yolov11n.py trains on 4-channel RGBT data using an early-fusion approach: the custom dataloader pre-combines RGB + thermal into a single 4-channel TIFF, and standard ultralytics (8.3.180) auto-adapts its first Conv layer to accept ch=4. This works but is architecturally equivalent to treating the thermal as a 4th colour channel — no modality-aware processing.

The goal is a new yolov11nrgbt.py script that uses the dedicated wandahangFY/YOLOv11-RGBT framework, which provides proper RGBT fusion architectures (mid-fusion, early-fusion, late-fusion) with separate backbone streams for RGB and thermal. Three fusion variants are needed so they can be compared.
